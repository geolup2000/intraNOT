# Project instructions

- Run the application locally. Do not deploy it to Sites, GitHub Pages or another host without an explicit request.
- Never commit or push PDF files, local backups, credentials, `.openai` metadata or deployment archives.
- The source lives in `orar/dist/`; this directory is intentionally tracked and is not a disposable build output.
- Keep the permanent discipline dictionary in source control. Unknown codes must not be expanded by guesswork.
- Run `npm run check` and `npm test` after code changes. No dependency installation is required for the app or these checks.
- Preserve the user's current schedule and PDF files when changing code.
